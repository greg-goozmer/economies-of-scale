## Запуск

Node.js 22.12+ или 24 LTS. В отдельном репозитории фронтенда команды выполняются из корня. В репозитории бэкенда сначала выполните `cd frontend`.

```powershell
npm ci
npm run dev
```

Открыть http://127.0.0.1:3000/costs. Для взаимодействия с бэкендом запустить из его корня:

```powershell
docker compose up -d
python -m alembic upgrade head
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

Бэкенду нужен собственный `.env` по `.env.example`. Существующая база и файлы в Docker volumes используются при повторном запуске. Зарегистрируйте пользователя на странице входа, пароль от 8 символов.

Без запущенного API гостю доступны каталог и лента из локальных mock-объектов. В интерфейсе видна отметка демонстрационного режима. Ошибки валидации и отсутствие прав отображаются сообщением. У авторизованного пользователя сетевые ошибки отображаются сообщением.

## Страницы

`/costs` — каталог издержек. На карточке изображение, название, код и число лайков. Поля «От»/«До» и двойной слайдер меняют значения фильтра Redux. «Применить» передаёт `min_cost_code` и `max_cost_code` в API, «Сбросить» очищает фильтр. Границы включительные, пустая граница означает отсутствие ограничения. Для собственной карточки отображается «Удалить». После удаления она исчезает из списка, сервер сохраняет строку со статусом `deleted`.

`/costs/feed` — первая опубликованная издержка. `/costs/feed/:costId` — выбранная карточка. Видео запускается без звука, описание ограничено двумя строками, «Ещё» раскрывает текст. Справа расположены лайк, параметры и «Далее». «Далее» вызывает серверную ленту с ID и `next=true`. Переход по кругу реализован в API. Создатель может поставить или отменить лайк. Гостю доступен просмотр количества лайков.

`/costs/login` — имя пользователя, пароль и «Войти». Кнопка создания учётной записи включает регистрацию с теми же полями. Вход и выход вызывают обычный Axios непосредственно из обработчиков компонентов. Результат входа передаётся в Redux обычным action. Сервер устанавливает HttpOnly-cookie `cost_session`, значение сессии хранится в Redis.

`/costs/draft` — добавление, доступное создателю. При открытии выполняется GET своего черновика. На первом шаге ровно три поля — название, файл изображения, файл видео. Предпросмотр использует временные object URL и освобождает их при изменении файла или уходе со страницы. «Далее» загружает файлы в MinIO и создаёт черновик. На втором шаге три поля — описание, тип (постоянные/переменные), целочисленный код. «Опубликовать» меняет статус через API и открывает каталог. Сохранённый черновик восстанавливается при повторном открытии страницы.

В нижнем меню четыре пункта — Лента, Добавление, Плитка, Вход/Выход. После входа включаются добавление, лайки и удаление собственных карточек. Во время запросов поверх интерфейса отображается индикатор, кнопки блокируются. Выход удаляет cookie на сервере, очищает пользователя и фильтр Redux. После F5 Redux создаётся заново в состоянии гостя, браузер сохраняет cookie до истечения срока или выхода. Для возврата в интерфейс создателя выполните вход повторно. Состояние в localStorage не сохраняется.

## Redux и кодогенерация

`src/store/costsStore.ts` содержит пользователя, введённые и применённые границы, список, карточку ленты, черновик, ошибки, счётчик запросов и источник данных. Операции домена издержек выполняются через `createAsyncThunk`, использующий сгенерированные методы Axios. Идентификаторы запросов защищают список и ленту от запоздалых ответов. При ответе 401 интерфейс возвращается в состояние гостя.

`src/api/generated/CostsApi.ts` генерируется из сохранённого `openapi.json`. Схема экспортирована из FastAPI. После изменения API сохраните новую схему и выполните генерацию:

```powershell
Invoke-WebRequest http://127.0.0.1:8000/openapi.json -OutFile openapi.json
npm run generate-api
```

`src/api/costsClient.ts` создаёт клиент с относительными адресами и передачей cookie. Vite проксирует `/api` на порт 8000 и `/s3` на MinIO 9000. URL изображения и видео из базы преобразуются в `/s3/costs/имя_файла`. В Network виден адрес фронтенда с префиксом прокси. Локальные медиа по умолчанию находятся в `public/media`.

## Проверки и показ

```powershell
npm run build
npm test
npm run test:e2e
```

Для браузерных проверок нужны Chrome, запущенный Vite, API и Docker-хранилища. Проверка создаёт отдельного пользователя с уникальным именем, публикует тестовую издержку и логически удаляет её. Исходные карточки не используются для удаления.
