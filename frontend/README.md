# Масштаб гостевой React интерфейс издержек

ЛР5 — базовое SPA на React и TypeScript. Ветка `react`. Стек: React 19, TypeScript 5, Vite 7, React-Bootstrap 2 и Bootstrap 5, React Router 7. Node.js 22.12+ или 24 LTS. Точные версии — package-lock.json.

## Запуск

```powershell
npm ci
npm run dev
```

Открыть http://localhost:3000/costs. Если проект открыт из бэкенд-репозитория, сначала `cd frontend`. PostgreSQL, Redis, MinIO, FastAPI для ЛР5 запускать не требуется. Все карточки берутся только из `src/modules/costsMock.ts`, все медиа — из `public/media`. Нет fetch, Axios, Redux, Context или подключения к API. Network показывает загрузку модулей и локальных медиа, но не запросы API.

```powershell
npm test
npm run build
npm run preview
```

Альтернативный запуск: `docker compose up --build` из папки фронтенда. Остановить: `docker compose down` без удаления томов бэкенда.

## Страницы и кнопки

### Плитка издержек /costs

Две колонки карточек: изображение, название, код издержки, тип постоянные/переменные и количество лайков. Нажатие карточки открывает `/costs/feed/:costId`. Поля фильтра «От» и «До» принимают целые неотрицательные коды, пустая граница не ограничивает выборку. Два бегунка изменяют те же значения в диапазоне 0–100; поля позволяют вводить и большие коды. «Применить» фильтрует mock по включительному диапазону, «Сбросить» возвращает всю коллекцию. До нажатия кнопки список не меняется. Неверный диапазон блокирует применение; пустой результат не заменяется полной коллекцией.

### Лента издержек /costs/feed/:costId

Вертикальное автоматически проигрываемое видео без звука, повторение и playsInline. Поверх видео название, описание в две строки и «Ещё»/«Свернуть», справа «⚙» открывает код и тип издержки. Лайки доступны только для просмотра: изменение лайков относится к ЛР6. «Следующая издержка» выбирает следующий ID из отфильтрованного массива, не ID+1; на последней карточке кнопка отключается. Прямая ссылка работает после F5 без API. Неизвестный ID даёт сообщение и ссылку к плитке.

### Нижнее меню

Четыре пункта: Лента, Добавление, Плитка, Вход. Доступны только Лента и Плитка. Лента открывает первую карточку текущего массива; при пустой выборке отключена. Добавление и Вход отключены, их формы не реализуются до ЛР6. Страниц два: фраза задания «три страницы» в порядке показа отражена тремя состояниями — плитка, плитка с фильтром, лента. Дополнительную работающую страницу авторизации в ЛР5 не добавляем.

Макет фиксированной ширины 390 px, без медиазапросов и адаптивного изменения структуры. При изменении окна меняется только центрирование; меню закреплено внизу колонки.

## Компоненты props и хуки

- `App`: `useState` хранит текущий массив издержек и передаёт его через props в страницы и меню.
- `CostTilesPage`: `useState` для двух границ; передаёт `minimum`, `maximum`, обработчики изменения, применения и сброса в `CostCodeFilter`.
- `CostCodeFilter`: управляемые поля React-Bootstrap `Form.Control`, `Form.Range`, `Button`; события передаются родителю через props, собственных копий состояния нет.
- `CostCard`: получает `cost` через props, выводит React-Bootstrap Card и ссылку React Router.
- `CostFeedPage`: `useParams` читает `costId`, `useNavigate` меняет карточку без перезагрузки, `useState` раскрывает описание/параметры; `useEffect` обновляет их при смене ID и задаёт document.title, cleanup восстанавливает заголовок.
- `CostTabBar`: `useLocation` определяет активную вкладку, `useNavigate` выполняет переходы.
- `CostImage` и `CostVideo`: `useState` переключает на локальную заглушку при ошибке. Если URL пустой, заглушка выбирается сразу.

## Медиа по умолчанию

`CostMedia.tsx`: `url || DEFAULT_COST_IMAGE` по смыслу реализован выбором src с проверкой пустого URL и ошибки. Картинка `/media/default-cost.svg`, видео `/media/default-cost.mp4` реально включены в проект. У mock «Подписка для кассы» (ID 8) оба URL пустые — готовый пример для демонстрации. SVG-обложки — учебные схемы собственного оформления, а не фотографии товаров. MP4 скопирован из учебной fixture предыдущей лабораторной.
