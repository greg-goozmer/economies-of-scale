# Показ ЛР6

Скриншоты соответствуют порядку показа ЛР6 из README преподавателя. Используйте http://127.0.0.1:3000. Откройте инструменты браузера F12. В Network перед каждым действием нажимайте значок очистки и выбирайте Fetch/XHR. На скрине показывайте страницу, адрес запроса, входные данные и JSON ответа.

1. Остановите только процесс Uvicorn. Откройте `/costs`, дождитесь отметки демонстрационных данных. Покажите шесть карточек и неуспешный запрос API. Подпись «Рисунок 1 — Каталог издержек из mock-коллекции при недоступном API».
2. Нажмите карточку, раскройте параметры. Подпись «Рисунок 2 — Лента издержек в гостевом mock-режиме».
3. Запустите API командой из README. Обновите каталог, поставьте границы 25–26, нажмите «Применить». В Network выберите costs, вкладку Headers с query, затем Response. Подпись «Рисунок 3 — Каталог издержек и серверная фильтрация по коду».
4. Нажмите «Вход», заполните имя и пароль, нажмите «Войти». Для нового пользователя сначала «Создать учётную запись». На скрине запроса `/api/users/auth` покажите входные поля во вкладке Payload и успешный ответ. Подпись «Рисунок 4 — Аутентификация пользователя через Axios».
5. Нажмите «Добавление». Укажите название и выберите настоящий PNG/JPEG/WebP и MP4/WebM. Покажите предпросмотр. После «Далее» откроются описание, тип и код. В Network для POST costs покажите Form Data с тремя входными полями и JSON ответа. Заполните три поля публикации, нажмите «Опубликовать». Подпись «Рисунок 5 — Создание и публикация собственной издержки с файлами».
6. Откройте опубликованную карточку в ленте, поставьте и отмените лайк. Покажите JSON POST `/api/costs/ID/likes` и изменившееся число. Подпись «Рисунок 6 — Лента издержек и управление лайками создателя». Удаление продемонстрируйте на своей тестовой карточке в каталоге.
7. Откройте Adminer http://127.0.0.1:8081. Движок PostgreSQL, сервер postgres, пользователь, пароль и база из `.env` бэкенда. В SQL выполните `SELECT cost_id, cost_name, cost_code, cost_status FROM costs ORDER BY cost_id;`. Запомните ID своей тестовой опубликованной карточки. Измените только её код запросом `UPDATE costs SET cost_code = 32 WHERE cost_id = ВАШ_ID;`. Подпись «Рисунок 7 — Изменение кода собственной тестовой издержки в PostgreSQL».
8. В каталоге сбросьте фильтр и обновите страницу. На своей карточке появится 32. Аналогично можно изменить description и проверить ленту. Подпись «Рисунок 8 — Отображение изменений базы данных во фронтенде».
9. Войдите, нажмите F5. В меню появится «Вход», добавление отключится. В F12 → Application → Cookies → http://127.0.0.1 выберите cost_session. В Redux DevTools покажите `costs.user = null`. Подпись «Рисунок 9 — Сброс состояния Redux при F5 с сохранением cookie-сессии».
10. Скопируйте Value cost_session из Application. В Postman GET `http://127.0.0.1:8000/api/costs`, Headers, белая галочка у Cookie, значение `cost_session=СКОПИРОВАННОЕ_ЗНАЧЕНИЕ`. В ответе найдите свою карточку с `is_owner: 1`. Покажите заголовок целиком и JSON. Подпись «Рисунок 10 — Использование браузерной сессии в Postman и признак владения издержкой».
11. В VS Code откройте `src/store/costsStore.ts`, интерфейс CostsState, initialState и reducers. Подпись «Рисунок 11 — Состояния пользователя, фильтра и данных издержек в Redux Toolkit».
12. Откройте `src/api/generated/CostsApi.ts`, найдите `axios.create` и `listCosts`. Подпись «Рисунок 12 — Сгенерированный Axios-клиент веб-сервиса издержек».
13. В `src/store/costsStore.ts` покажите loadCosts, параметры фильтра и вызов `costsApi.api.listCosts`. Подпись «Рисунок 13 — Получение списка издержек через сгенерированный метод внутри thunk».
14. Покажите createCostDraft, publishCostDraft и changeCostLike, затем их dispatch в страницах. Подпись «Рисунок 14 — Создание, публикация и лайк издержки через Redux Thunk».
15. В Network каталога выберите costs → Headers. Request URL должен начинаться с `http://127.0.0.1:3000/api/costs`. Рядом откройте `vite.config.ts` с `/api` и `/s3`. Подпись «Рисунок 15 — Обращение к API через обратный прокси Vite».
16. Network → Img либо Media. Нажмите файл реальной карточки, Headers. Покажите URL `/s3/costs/имя_файла` и исходный URL `http://localhost:9000/costs/...` в JSON ответа API. Подпись «Рисунок 16 — Загрузка изображений и видео из MinIO через прокси».
17. В StarUML откройте `docs/costs_database.mdj`, в дереве модель «ЛР6 Прецеденты интерфейса издержек», диаграмму «ЛР6 Гость и создатель издержек». Подпись «Рисунок 17 — Диаграмма прецедентов интерфейса издержек для гостя и создателя».

Для проверки после показа выйдите через меню. Фильтр очистится, cookie удалится, добавление и лайки станут недоступны. При логическом удалении запись costs остаётся в PostgreSQL со статусом deleted.
