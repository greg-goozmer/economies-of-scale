# ЛР5 контрольные вопросы

- React — библиотека построения интерфейсов из компонентов; состояние и props определяют результат render.
- Компонент — функция, возвращающая React элементы. Элемент — описание конкретного узла интерфейса, не сам DOM узел.
- Props — входные значения от родителя, только чтение. State — внутренние изменяемые через setter данные компонента, изменение инициирует render.
- useState возвращает значение и setter. В ЛР — границы фильтра, массив карточек, раскрытие описания и параметров, ошибка медиа.
- useEffect синхронизирует компонент с внешней системой после render. Зависимости определяют повторный запуск; cleanup выполняется перед новым эффектом и при размонтировании. В ЛР меняет document.title и сбрасывает раскрытия при смене ID. В dev StrictMode возможен дополнительный проверочный setup/cleanup.
- Жизненный цикл: монтирование, обновление, размонтирование. useEffect не описывает весь жизненный цикл и не вызывается вместо render.
- useNavigate — переход без загрузки нового HTML; useParams — costId из URL; useLocation — активная вкладка по pathname.
- Управляемое поле: value берётся из state, onChange вызывает setter. CostCodeFilter получает значения и обработчики через props; фильтрует родитель по submit.
- Vite — dev сервер, HMR и production сборка. TypeScript проверяет типы; TSX описывает элементы. Babel — JavaScript трансформатор, используется инструментами React для преобразований; сам TypeScript не проверяется Babel.
- Mock — локальная типизированная коллекция, не серверный JSON. Переходы и фильтрация не создают запросов к API; в Network видны модули и локальные изображения/видео.
- Почему не Redux и Context: в ЛР5 они не требуются и Context запрещён. Общий массив передаётся через props, Redux Toolkit относится к ЛР6.
- Почему только две вкладки доступны: задание ЛР5 — гостевое чтение. Добавление и Вход показаны отключёнными, операции записи и авторизация появятся в ЛР6.
- Изображение и видео по умолчанию — реальные локальные файлы public/media, используются при пустом URL; ошибка загрузки переключает на них через состояние failed.
