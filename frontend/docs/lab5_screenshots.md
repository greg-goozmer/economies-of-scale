# ЛР5 десять скриншотов для показа

## Подготовка

В терминале папки фронтенда: `npm ci`, затем `npm run dev`. Открыть http://localhost:3000/costs. Бэкенд и Docker для показа ЛР5 не нужны: данные mock, медиа локальные. В Chrome F12 → Network → All, включить Disable cache при открытой панели. Не включать режим Offline: Vite тоже сервер, только фронтенда.

Формулировка «три страницы» в порядке показа не должна превращать отключённые вход/добавление в новые рабочие страницы: задание требует две доступные вкладки. Снять три состояния двух экранов — список, фильтр, ленту.

Развернуть браузер, при необходимости отделить DevTools через ⋮ → Dock side → отдельное окно. Снимать крупно Win+Shift+S: интерфейс, URL и Network должны читаться. В Word под каждым кадром подпись «Рисунок N — ...». Не выдавать mock за ответ API: в Network нет `/api/costs`.
