# ЛР4 Конспект и ответы

## Лекция 6

ТЗ задаёт цель, пользователей, задачи, функции и требования итоговой системы. Аутентификация проверяет личность, авторизация — разрешённые действия. При серверной сессии cookie содержит случайный ключ, состояние пользователя находится в Redis. TTL ограничивает срок действия, выход отзывает сессию. Swagger описывает и позволяет выполнять HTTP-запросы.

## Лекция 7

Цифровая подпись подтверждает автора и целостность данных. В асимметричной схеме закрытый ключ подписывает, открытый проверяет. JWT состоит из header.payload.signature; подпись не шифрует содержимое. Для досрочного отзыва JWT может применяться blacklist. В нашей FastAPI-работе по заданию используются cookie и Redis, без JWT.

## Короткие ответы для защиты

1. Cookie — значение, выдаваемое Set-Cookie и возвращаемое браузером через Cookie. У нас cost_session; HttpOnly запрещает чтение JavaScript, SameSite=Lax ограничивает межсайтовую отправку, Secure требует HTTPS.
2. Сессия — серверное состояние входа. Redis хранит ID по SHA256 случайного токена; срок по умолчанию 3600 секунд.
3. Redis — быстрое хранилище ключ–значение с TTL. SET EX создаёт сессию, GET читает пользователя, DEL отзывает, TTL показывает срок.
4. JWT — подписанный токен из трёх частей с данными о пользователе и сроке. Не шифрование. В нашей работе не используется.
5. Аутентификация — кто ты, проверка пароля. Авторизация — что можно: например, публиковать только свой черновик.
6. SSO — один вход в несколько приложений через доверенного провайдера. В ЛР не реализован.
7. Два фактора — независимые виды подтверждения, например пароль и одноразовый код. Два пароля не являются двумя факторами. В ЛР не реализованы.
8. RSA — асимметричный алгоритм с открытым и закрытым ключами для подписи/шифрования с соответствующими схемами. У нас пароль хешируется PBKDF2, не RSA.

## Где смотреть реализацию

`core/passwords.py` — PBKDF2 и соль. `api/user_api.py` — регистрация, вход, cookie, выход. `api/current_user.py` — реальный ID из Redis вместо константы 101. `db/redis.py`, `main.py` — Redis-клиент. `api/cost_api.py` — публичное чтение и защищённые изменения. При создании три входных поля, при публикации три; 14 полей карточки — выходные.
