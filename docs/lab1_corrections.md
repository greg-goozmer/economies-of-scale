# Исправления первой лабораторной, перенесённые в ЛР2

- Все предметные имена заменены на названия, связанные с издержками.
- Навигационная лента перенесена вниз.
- Описание в ленте ограничено двумя строками и раскрывается через «Ещё».
- Лайки и параметры находятся справа; предметные параметры скрыты под типичной иконкой настроек.
- Фильтр по числовым кодам выполнен двойным слайдером с кнопкой применения.
- Лишняя кнопка на форме добавления удалена в ЛР1; в ЛР2 появились только обязательные кнопки «Далее» и «Опубликовать».
- Вместо суммы используется числовой код издержки.
