# Масштаб — лабораторная работа №1 по РИП

Каталог издержек кофейного уголка по теме «Оценка экономии от масштаба». Пользователь просматривает статьи расходов и отбирает их по месячной сумме. Базовый объём для данных — 1000 напитков в месяц.

В ЛР1 реализован каталог, а не расчёт экономии от масштаба: нет заявок, корзины, расчёта средних издержек, авторизации и базы данных.

## Технологии

- Python 3.12, FastAPI и Uvicorn.
- Jinja2: сервер формирует HTML до отправки браузеру.
- HTML, встроенная SVG-разметка и отдельный CSS; без JavaScript.
- MinIO через Docker Compose для хранения изображений и видео.
- Одна Python-коллекция для данных; денежные значения — `Decimal`.

## Экраны

| Страница | Адрес | Возможности |
|---|---|---|
| Лента | `/costs/feed` | Видео с автозапуском без звука, названием, описанием, видом расходов, суммой и числом лайков. Стрелка вниз открывает следующую карточку; после последней — первую. |
| Добавление | `/costs/draft` | Данные черновика «Порционный сахар», превью изображения и видео, поля ввода и выбора файлов. Кнопка публикации отключена. |
| Плитка | `/costs` | Опубликованные карточки в две колонки, фильтр по максимальным месячным расходам и переход в ленту. |

Размер интерфейса — 360 × 704 px, нижняя навигация — 64 px. Лайки показывают данные коллекции и не изменяются при нажатии. Изменения полей черновика не сохраняются, выбранные файлы не загружаются; перезагрузка возвращает исходные значения.

## Первый запуск в Windows / PowerShell

Потребуются Python 3.12 и запущенный Docker Desktop с Linux-контейнерами. Команды выполняются из корня проекта.

Создайте виртуальное окружение и установите зависимости:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Если `.env` ещё нет, создайте его из примера:

```powershell
Copy-Item .env.example .env
```

В `.env` задайте собственные локальные `MINIO_ROOT_USER` и `MINIO_ROOT_PASSWORD` (пароль — минимум 8 символов). Не перезаписывайте существующий `.env`: в нём находятся данные входа в вашу локальную MinIO Console. Файл исключён из Git; `.env.example` содержит только заполнители.

Запустите MinIO и приложение:

```powershell
docker compose up -d
docker compose ps
.\.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

Оставьте терминал с Uvicorn открытым. FastAPI запускается отдельно от Docker Compose.

- [Лента](http://localhost:8000/costs/feed)
- [Добавление](http://localhost:8000/costs/draft)
- [Плитка](http://localhost:8000/costs)
- [MinIO Console](http://localhost:9001)

Адрес `/` и страницы `/docs`, `/redoc`, `/openapi.json` намеренно не предусмотрены — открывайте один из трёх адресов приложения.

## Запуск после перезагрузки

Откройте Docker Desktop, дождитесь запуска движка и выполните из корня проекта:

```powershell
docker compose up -d
.\.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

Повторно создавать окружение и загружать медиа не требуется, если локальные данные сохранены. Для остановки FastAPI нажмите `Ctrl+C`. Для остановки MinIO:

```powershell
docker compose down
```

Не добавляйте `-v`: этот флаг удаляет volume с медиа. Обычные `down` и `up -d` сохраняют файлы.

## Медиа и MinIO

MinIO API доступен по `http://localhost:9000`, консоль — по `http://localhost:9001`. Оба порта привязаны к локальному компьютеру.

Одноразовый контейнер `minio-init` создаёт bucket `coffee-costs`, если его ещё нет, и назначает политику `download`: анонимное чтение разрешено, анонимная запись запрещена. Завершение этого контейнера с кодом 0 после настройки — нормальное поведение. Данные хранятся в именованном volume `minio_data`.

На новом компьютере медиа нужно загрузить отдельно: Git содержит код и ссылки, но не содержимое MinIO. Войдите в консоль с данными из `.env`, откройте bucket `coffee-costs` и загрузите 14 объектов в его корень без вложенных папок:

| Статья | Изображение | Видео |
|---|---|---|
| Аренда кофемашины | `coffee_machine_rental.png` | `coffee_machine_rental.mp4` |
| Подписка для кассы | `cash_register_subscription.png` | `cash_register_subscription.mp4` |
| Кофейное зерно | `coffee_beans.png` | `coffee_beans.mp4` |
| Молоко | `milk.png` | `milk.mp4` |
| Бумажные стаканы | `paper_cups.png` | `paper_cups.mp4` |
| Крышки для стаканов | `cup_lids.png` | `cup_lids.mp4` |
| Порционный сахар | `sugar_sticks.png` | `sugar_sticks.mp4` |

Изображения используются в плитке, как постеры видео и в превью черновика. Вертикальные MP4 воспроизводятся без звука по кругу. Превью черновика открывают соответствующий медиафайл в новой вкладке.

Пример прямой ссылки: `http://localhost:9000/coffee-costs/coffee_beans.png`. Браузер получает медиа напрямую из MinIO; FastAPI не проксирует файлы и не использует MinIO SDK. Исходные PNG и MP4 необходимо хранить отдельно для переноса проекта на другой компьютер.

## Структура проекта

```text

  cost_handlers.py          Три GET-обработчика, проверка параметров, фильтрация

  coffee_costs.py           Коллекция статей и базовый объём выпуска

  cost_base.html            Общий HTML-каркас и нижняя навигация
  cost_feed.html            Лента
  cost_draft.html           Черновик
  cost_tiles.html           Плитка и фильтр

docker-compose.yml          MinIO, одноразовая настройка bucket и volume
```

Отдельные SVG-макеты для запуска не нужны: используемая SVG-разметка находится внутри Jinja2-шаблонов.

## Данные и обработка запросов

`coffee_costs` — список из семи словарей: шесть опубликованных статей с ID 1–6 и один черновик с ID 7. Статусы предусматривают `published`, `draft`, `deleted`. В ленту и плитку попадают только опубликованные записи, отсортированные по ID.

Два тематических поля: `cost_behavior` (`fixed` / `variable`) и `monthly_cost_rub`. Суммы заранее записаны в коллекции как `Decimal`, созданные из строк, и сравниваются без преобразования во `float`. Количество лайков вычисляется обработчиком как длина вложенного списка `cost_liked_by`. Коллекция также содержит названия, описания, ссылки на медиа, источники цен и даты их проверки.

Параметр `cost_id` выбирает карточку. `next=true` показывает следующую после указанной; без ID открывается первая. Ссылка следующего перехода строится от отображённой карточки. Фильтр плитки не ограничивает последующее листание ленты.

Порог `max_monthly_cost` включается в результат: сумма статьи должна быть меньше или равна ему. Разрешены точка или запятая и до двух дробных знаков; пробелы по краям убираются. Введённый текст сохраняется в поле, включая ошибочный ввод. Ошибки возвращаются как HTML со статусом 400 или 404.

## Проверка и демонстрация на защите

К адресам в таблице добавляйте `http://localhost:8000`:

| Запрос | Ожидаемый результат |
|---|---|
| `/costs/feed` | 200, первая опубликованная статья |
| `/costs/feed?cost_id=3` | 200, кофейное зерно |
| `/costs/feed?cost_id=6&next=true` | 200, переход к ID 1 |
| `/costs/feed?next=true` | 200, ID 1 |
| `/costs/feed?cost_id=7` | HTML 404, черновик скрыт |
| `/costs/feed?cost_id=999` | HTML 404, статья не найдена |
| `/costs/feed?next=bad` | HTML 400 |
| `/costs/draft` | 200, черновик сахара; ввод не сохраняется |
| `/costs` | 200, шесть карточек |
| `/costs?max_monthly_cost=10000` | 200, ID 1, 2, 5, 6 |
| `/costs?max_monthly_cost=332.50` | 200, только ID 2 |
| `/costs?max_monthly_cost=332,50` | Тот же результат |
| `/costs?max_monthly_cost=0` | 200, пустой результат |
| `/costs?max_monthly_cost=` | 200, все шесть карточек |
| `/costs?max_monthly_cost=-1` | HTML 400 |
| `/costs?max_monthly_cost=abc` | HTML 400 |
| `/costs?max_monthly_cost=1.001` | HTML 400, больше двух дробных знаков |

В DevTools → Network покажите GET-запросы страниц, готовый HTML в Response и отдельные обращения браузера к MinIO на порту 9000. Для видео возможен ответ 206 Partial Content — загрузка диапазона байтов.

Для объяснения архитектуры: коллекция — модель; обработчики выбирают данные и формируют контекст; Jinja2-шаблоны — представление. GET-форма передаёт порог в URL, фильтрация выполняется на сервере. CSS и медиа обслуживаются отдельно от трёх прикладных маршрутов.

## Если что-то не открывается

- `ERR_CONNECTION_REFUSED` на порту 8000: проверьте, запущен ли Uvicorn и открыт ли его терминал.
- Ошибка Docker: запустите Docker Desktop и дождитесь готовности движка.
- Медиа возвращают 404: проверьте имена объектов, расширения `.png` / `.mp4` и отсутствие вложенной папки в bucket.
- Медиа возвращают 403: проверьте логи `docker compose logs minio-init` и политику чтения bucket.
- После обновления остались старые стили: нажмите `Ctrl+F5`.
- После клонирования картинки отсутствуют: загрузите исходные медиа в локальный MinIO по таблице выше.
